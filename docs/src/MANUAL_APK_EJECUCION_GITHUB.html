NEXO DEMO

Ejecutar, generar el APK y publicar

Guia de entrega para el proyecto Android, el APK de demostracion y GitHub.

Nexo es una demostracion local. No se conecta a bancos, no paga obligaciones reales y no concede prestamos.

1. Abrir el proyecto correcto

banca mobile/
|-- README.md
|-- docs/                  PDF y fuentes HTML
`-- banca_movile/
    |-- android-app/       Proyecto Gradle
    |-- distribucion/      APK de entrega
    `-- scripts/           Generador de PDF

Abre exactamente banca_movile/android-app en Android Studio. No abras solo app ni la carpeta exterior.

2. Requisitos

  • Android Studio actualizado, Android SDK 37 y JDK 17 o superior.
  • Android 7.0 (API 24) o superior para ejecutar la app.
  • Internet durante la primera sincronizacion de dependencias.
  • Git solo si vas a publicar el proyecto.

3. Ejecutar desde Android Studio

  1. Selecciona Open y abre banca_movile/android-app.
  2. Espera a que termine Gradle Sync.
  3. Inicia un emulador o conecta un dispositivo con depuracion USB.
  4. Selecciona la configuracion app y pulsa Run.

Credenciales: demo@nexo.com / Nexo2026.

COMPILACION

Verificar y entregar

4. Comandos principales

Ejecuta los comandos desde banca_movile/android-app:

.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleDebug

Verificacion completa:

.\gradlew.bat clean :app:testDebugUnitTest :app:lintDebug :app:generarApkDemo

5. Crear el APK de entrega

.\gradlew.bat :app:generarApkDemo

El resultado queda en banca_movile/distribucion/Nexo-Demo.apk. Es un APK firmado para depuracion, adecuado solo para clases y demostraciones.

6. Instalar mediante ADB

adb devices
adb install -r ".\app\build\outputs\apk\debug\app-debug.apk"
adb shell am start -n com.nexo.banca.demo/com.nexo.banca.MainActivity

7. Regenerar los manuales

Todo cambio visible debe reflejarse en README, la guia de desarrollo y los archivos afectados de docs/src. Luego, desde la raiz del repositorio:

.\banca_movile\scripts\generar-documentos.ps1

El script usa Microsoft Edge en modo headless y reemplaza los tres PDF de docs.

GITHUB

Publicar codigo y APK

8. Preparar Git

El repositorio debe incluir codigo y documentacion. No agregues build/, .gradle/, .idea/, local.properties, APK, secretos o claves de firma.

git status
git add .
git commit -m "Actualiza Nexo Demo"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/nexo-banca-demo.git
git push -u origin main

Si el repositorio ya tiene un remoto, revisalo con git remote -v. No guardes credenciales dentro del proyecto.

9. Publicar el APK como Release

  1. Genera banca_movile/distribucion/Nexo-Demo.apk.
  2. En GitHub abre Releases > Draft a new release.
  3. Crea una etiqueta, por ejemplo v2.0-demo.
  4. Describe biometria automatica configurable, temas Sistema/Claro/Oscuro, transferencias QR, navegacion Inicio/Movimientos/Mas y las pestañas de servicios, creditos y calculadora.
  5. Adjunta el APK y docs/GUIA_INSTALACION_APK.pdf.
  6. Publica la Release. No agregues el APK al historial Git.

10. Diagnostico rapido

ProblemaAccion
Gradle Sync fallaComprueba Internet, SDK 37 y el JDK configurado en Android Studio.
No aparece el APKBusca BUILD SUCCESSFUL y repite :app:generarApkDemo.
El telefono no apareceActiva depuracion USB, acepta la clave RSA y ejecuta adb devices.
Conflicto al instalarDesinstala la copia anterior; recuerda que esto elimina sus datos locales.
